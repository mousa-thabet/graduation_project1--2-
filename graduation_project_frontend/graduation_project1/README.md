# AreaTk | منصة التواصل التعليمي

منصة تعليمية للطلاب تجمع بين الدراسة مع الآخرين وتبادل المعرفة وتنظيم الوقت، وهي مقسّمة إلى ثلاثة أقسام:

- **ادرس معي:** جلسات دراسة بمؤقّت (بومودورو) مع أصوات وخلفيات للتركيز، وبثوث دراسة مباشرة، ومنشورات قصيرة عن الإنجاز، وسجلّ الجلسات، ومكتبة الأصوات والخلفيات.
- **التواصل:** مجتمعات حسب التخصص وفروعها، وأسئلة وإجابات، وامتحانات ودورات يُنشئها الطلاب، وبثّ شرح، وشارات للخبرة.
- **خطتي:** خطة يومية وأسبوعية مترابطة؛ المهمة المضافة ليوم معيّن تظهر في الخطة اليومية لذلك اليوم وفي الخطة الأسبوعية معًا.

ويتضمن الموقع كذلك لوحة إدارة لمراجعة الشارات والبلاغات وطلبات الفروع ورفع الأصوات والخلفيات.

> هذا المستودع هو **الواجهة الأمامية فقط**. البيانات حاليًا محفوظة في متصفح المستخدم بدل الخادم، وتفاصيل ذلك في قسم [ملاحظات للباك إند](#ملاحظات-للباك-إند).

## التشغيل

المتطلبات: **Node.js 20.19** أو أحدث (أو 22.12 فما فوق).

```bash
npm install      # تثبيت المكتبات (مرة واحدة)
npm run dev      # تشغيل الموقع للتطوير على http://localhost:5173
```

أوامر أخرى:

| الأمر | الوظيفة |
|---|---|
| `npm run build` | بناء نسخة الإنتاج في مجلد `dist` |
| `npm run preview` | تشغيل نسخة الإنتاج المبنية للتجربة |
| `npm run lint` | فحص الكود بأداة oxlint |

### الدخول للتجربة

- **حساب طالب:** أي اسم حساب وأي كلمة مرور من صفحة تسجيل الدخول (لا يوجد تحقق حقيقي قبل ربط الخادم).
- **لوحة الإدارة:** من صفحة تسجيل الدخول نفسها باسم الحساب `admin` وكلمة المرور `Areatk@2026`، فينتقل الموقع تلقائيًا إلى لوحة الإدارة.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| React 19 | بناء الواجهة |
| Vite | التشغيل والبناء |
| React Router | التنقل بين الصفحات |
| i18next و react-i18next | دعم العربية والإنجليزية مع اتجاه الصفحة (من اليمين لليسار وبالعكس) |
| خط Cairo | الخط العربي للموقع |
| localStorage و IndexedDB | حفظ البيانات مؤقتًا في المتصفح (بدل الخادم) |

لا توجد مكتبات تصميم جاهزة؛ كل التنسيقات مكتوبة بـ CSS عادي، والألوان في متغيرات داخل `src/index.css`، وتدعم الوضعين الفاتح والداكن.

## ملاحظات للباك إند

الواجهة مكتملة وتعمل دون خادم: كل البيانات تُحفظ في متصفح المستخدم، وبعض ردود الخادم مُحاكاة. عند ربط الخادم يُستبدل الحفظ المحلي بطلبات API **داخل ملفات `src/hooks/` فقط**، أما الصفحات فتبقى كما هي لأنها تأخذ البيانات من هذه الـ hooks.

### أين تُحفظ البيانات حاليًا

كل مفتاح في localStorage يبدأ بـ `areatk-`، وكل ميزة لها hook مسؤول عنها. **شكل البيانات نفسها وحقولها في ملف [`DATA.md`](DATA.md).**

| الميزة | الملف | مفتاح الحفظ |
|---|---|---|
| تسجيل الدخول | `hooks/useAuth.js` | `areatk-auth` |
| صلاحية الإدارة | `hooks/useAdmin.js` | `areatk-admin-session` |
| الحساب (الاسم، النبذة، الصورة) | `hooks/useProfile.js` | `areatk-profile:<اسم الحساب>` |
| حساب التواصل (التخصص، الغلاف) | `hooks/useCommunityProfile.js` | `areatk-community-profile:<اسم الحساب>` |
| منشورات ادرس معي والتواصل | `hooks/useStudyPosts.js` | `areatk-study-feed`، `areatk-community-feed` |
| المسودات | `hooks/useDrafts.js` | `areatk-drafts`، `areatk-community-drafts` |
| المتابعة (مشتركة بين القسمين) | `hooks/useFollowing.js` | `areatk-following` |
| الإشعارات | `hooks/useNotifications.js` | `areatk-notifications:<اسم الحساب>` |
| جلسة الدراسة وإحصائياتها | `hooks/useStudySession.js`، `useSessionTimer.js`، `useSessionStats.js` | `areatk-session`، `areatk-session-plan`، `areatk-session-stats` |
| البثوث | `hooks/useStreams.js` | `areatk-streams` |
| المكتبة والأصوات والخلفيات | `hooks/useMyLibrary.js`، `useMySounds.js`، `useMyScenes.js`، `useOfficialLibrary.js` | `areatk-my-library`، `areatk-my-sounds`، `areatk-my-scenes`، `areatk-official-library` |
| الخطة | `hooks/usePlan.js` | `areatk-plan` |
| عضوية المجتمعات والفروع | `hooks/useMemberships.js` | `areatk-community-memberships` |
| المجتمعات والفروع الجديدة | `data/communities.js` | `areatk-community-custom-communities`، `areatk-community-custom-branches` |
| الامتحانات ونتائجها | `hooks/useExams.js` | `areatk-community-exams`، `areatk-community-exam-results` |
| الدورات والتقدّم فيها | `hooks/useCourses.js` | `areatk-community-courses`، `areatk-community-course-progress` |
| الشارات | `hooks/useBadges.js` | `areatk-community-badges` |
| طلبات الفروع | `hooks/useBranchRequests.js` | `areatk-community-branch-requests` |
| البلاغات والحجب وطلبات المراجعة | `hooks/useReports.js`، `useModeration.js` | `areatk-community-reports`، `areatk-community-blocks`، `areatk-community-appeals` |

الوضع الفاتح أو الداكن واللغة تفضيلات خاصة بالجهاز، ويمكن أن تبقى في المتصفح.

### الملفات (الصور والفيديو والصوت)

ما يرفعه المستخدم يُحفظ في **IndexedDB** (قاعدة `areatk-media`) عبر `src/utils/mediaStore.js`، وفي البيانات يُخزَّن رقم الملف (`mediaId`) فقط. عند ربط الخادم تُرفع الملفات إليه، ويصبح `mediaId` رابط الملف.

### ما يجب استبداله بالخادم

- **`src/utils/simulateServer.js`:** يحاكي وصول إعجاب على المنشور بعد ثوانٍ. يُحذف عند ربط الخادم.
- **تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور:** تقبل أي بيانات حاليًا، وتنتظر لحظة ثم تنجح.
- **الإدارة:** الحساب التجريبي `admin` موجود في `hooks/useAdmin.js`، والصلاحية يجب أن يفحصها الخادم لا المتصفح.
- **`src/data/currentUser.js`:** المستخدم الحالي يُقرأ من حساب تسجيل الدخول.
- **`src/data/`:** المنشورات والأشخاص والمجتمعات فيها بيانات تجريبية للعرض، تُستبدل ببيانات الخادم.
- **التحديث بين التبويبات** (`hooks/useSharedStorage.js`): يُستبدل بتحديث من الخادم (WebSocket أو طلبات دورية).

في الكود تعليقات تبدأ بكلمة **«لاحقًا»** عند كل موضع يحتاج ربطًا بالخادم؛ البحث عنها يُظهر كل هذه المواضع.
