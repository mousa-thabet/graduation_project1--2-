# شكل البيانات في AreaTk

هذا الملف يصف **كل نوع بيانات تستخدمه الواجهة** وحقوله ومعنى كل حقل، كما هو مكتوب في الكود حاليًا. الهدف أن تُبنى قاعدة البيانات والـ API بنفس الأسماء والأشكال، فيعمل الربط بين الواجهة والخادم من أول مرة.

> مكان حفظ كل نوع حاليًا (localStorage أو IndexedDB) والملف المسؤول عنه موجودان في `README.md`، قسم «ملاحظات للباك إند».

---

## قواعد عامة

| القاعدة | التفصيل |
|---|---|
| **الأرقام التعريفية (`id`)** | نصوص، وليست أرقامًا (مثل `"post-1"` أو `"exam-…"`). |
| **الأوقات** | كل حقل وقت (`createdAt`، `updatedAt`، `startedAt`...) رقم بالملّي ثانية منذ 1970 (`Date.now()`)، وليس نص تاريخ. |
| **أسماء الحقول** | بأسلوب camelCase (`createdAt` وليس `created_at`). إن استخدم الخادم أسلوبًا آخر يجب التحويل قبل إرسال البيانات للواجهة. |
| **النصوص بلغتين** | أسماء المجتمعات والفروع وما تضيفه الإدارة تكون كائنًا بلغتين: `{ "ar": "…", "en": "…" }`. أما ما يكتبه المستخدم (منشور، سؤال، نبذة) فنص واحد كما كتبه. |
| **الملفات** | الصور والفيديو والصوت لا تُخزَّن داخل البيانات؛ يُخزَّن رقمها `mediaId` فقط، والملف نفسه منفصل. عند الربط يصبح `mediaId` (أو حقل جديد بجانبه) رابط الملف على الخادم. |
| **حقول خاصة بالمستخدم الحالي** | حقول مثل `isMine` و`isLiked` و`isSaved` و`isReported` و`myVote` و`isRead` **لا تُخزَّن على العنصر نفسه**، بل تُحسب لكل مستخدم من علاقته بالعنصر. الخادم يرسلها محسوبة للمستخدم الذي طلب البيانات. |
| **العدّادات** | `likes` و`reports` و`students` و`members` و`views` أرقام يرسلها الخادم جاهزة. |

## 1. الحساب وتسجيل الدخول

### إنشاء حساب (صفحة `/register`)

| الحقل | النوع | القواعد في الواجهة |
|---|---|---|
| `username` | نص | 3 أحرف على الأقل، أحرف إنجليزية وأرقام و`_` و`.` فقط |
| `email` | نص | بريد إلكتروني صالح |
| `password` | نص | 8 أحرف على الأقل، وفيها حرف كبير ورقم |
| `confirmPassword` | نص | مطابقة لكلمة المرور (للواجهة فقط، لا تُرسل للخادم) |
| `terms` | منطقي | الموافقة على الشروط |

### تسجيل الدخول (صفحة `/login`)

| الحقل | النوع | الملاحظة |
|---|---|---|
| `account` | نص | اسم المستخدم **أو** البريد الإلكتروني |
| `password` | نص | |

الجلسة المحفوظة حاليًا: `{ "account": "hamza", "loggedInAt": 1731590400000 }`. عند الربط يُحفظ بدلها الرمز (token) الذي يرجعه الخادم، ومعه دور المستخدم (طالب أو `admin`).

### استعادة كلمة المرور (صفحة `/forgot-password`)

ثلاث خطوات: إرسال اسم الحساب أو البريد ← إدخال **رمز من 6 أرقام** يصل بالبريد ← كلمة مرور جديدة (بنفس قواعد إنشاء الحساب).

### الشخص المختصر (يظهر كاتبًا للمنشورات والتعليقات وفي القوائم)

```json
{
  "id": "p1",
  "name": "لين",
  "handle": "leen.focus",
  "avatar": "رابط الصورة أو null",
  "badges": [{ "type": "scholar" }, { "type": "expert", "communityId": "ai" }]
}
```

`handle` هو اسم المستخدم الظاهر بعد `@`، ويُستخدم في رابط الحساب (`/profile/leen.focus`).

## 5. الشارات

| النوع (`type`) | المعنى | حقول إضافية |
|---|---|---|
| `expert` | درع أزرق: خبرة في مسار معيّن | `communityId`: المسار |
| `scholar` | درع أخضر: قيمة علمية (دكتور، باحث، مدرّب) | — |

**صلاحيات الشارات:** `scholar` تسمح بنشر الامتحانات والدورات وبث الشرح. وأي شارة تسمح بطلب فتح فرع جديد. **يجب أن يتحقق الخادم من هذه الصلاحيات**، لا الواجهة فقط.

### طلب شارة

```json
{
  "id": "…",
  "type": "expert",
  "communityId": "frontend",
  "about": "تعريف بخبرته",
  "proofName": "certificate.pdf",
  "proofMediaId": "رقم ملف الإثبات",
  "applicant": { "id": "me", "handle": "hamza" },
  "status": "pending",
  "reason": null,
  "createdAt": 1731590400000,
  "reviewedAt": null,
  "isNotified": false
}
```

- `status`: `pending` (قيد المراجعة) أو `approved` (مقبول) أو `rejected` (مرفوض).
- `reason`: سبب الرفض، من: `notEnough` (الإثبات غير كافٍ) أو `proofUnclear` (الإثبات غير واضح).
- `isNotified`: هل وصل صاحب الطلب إشعار بالقرار.

### الخبرة الموثّقة (صفحة الخبرات عند الضغط على الدرع)

مفتاحها `"scholar"` أو `"expert:<communityId>"`:

| الحقل | المعنى |
|---|---|
| `credential` | الشهادة أو المسمى |
| `details` | تعريف بالخبرة |
| `proof` | نوع الإثبات: `certificate` أو `portfolio` أو `companyLetter` |
| `verifiedAt` | وقت موافقة الإدارة |

## 6. المنشورات

نفس الشكل في القسمين، وكل قسم له منشوراته المنفصلة.

| الحقل | النوع | المعنى |
|---|---|---|
| `id` | نص | |
| `author` | شخص مختصر | الكاتب |
| `createdAt` | وقت | وقت النشر |
| `editedAt` | وقت (اختياري) | وقت آخر تعديل |
| `text` | نص | المحتوى، وقد يحتوي وسومًا `#…` وإشارات `@…` |
| `media` | كائن أو null | صورة أو فيديو أو صوت (الشكل تحت) |
| `poll` | كائن أو null | استطلاع (الشكل تحت) |
| `likes` | رقم | عدد الإعجابات |
| `reports` | رقم | عدد البلاغات |
| `comments` | قائمة | التعليقات والردود |

**حقول خاصة بالمستخدم الحالي:** `isMine`، و`isLiked`، و`isSaved`، و`isReported`.

**الوسائط (`media`):**
```json
{ "type": "image", "name": "photo.jpg", "mediaId": "رقم الملف" }
```
`type`: `image` أو `video` أو `audio`.

**الاستطلاع (`poll`):**
```json
{ "options": [ { "id": "o1", "text": "الصبح بكير", "votes": 42 } ] }
```
لكل مستخدم صوت واحد فقط، ويصل للواجهة في `myVote` (رقم الخيار الذي اختاره).

**منشور إنجاز (ادرس معي):** منشور يُشارَك بعد جلسة دراسة، فيه:
```json
{ "kind": "achievement", "achievement": { "minutes": 150, "task": "مراجعة التطبيع", "streak": 6 } }
```

**حقول إضافية في التواصل:**

| الحقل | النوع | المعنى |
|---|---|---|
| `type` | نص | `post` (منشور) أو `question` (سؤال) أو `live` (بث مباشر). الواجهة تدعم أيضًا عرض `video` (تبويب الفيديوهات)، لكن صندوق النشر لا يُنشئه حاليًا |
| `communityId` | نص | المجتمع |
| `branchId` | نص أو null | الفرع داخل المجتمع |
| `tags` | قائمة نصوص | وسوم الأدوات (مثل `React`) |
| `live` | كائن (للبث فقط) | `{ "status": "live" أو "ended", "startedAt", "endedAt", "thumbnail", "isRecorded" }` |

### التعليق

| الحقل | النوع | المعنى |
|---|---|---|
| `id` | نص | |
| `author` | شخص مختصر | |
| `createdAt` | وقت | |
| `text` | نص | |
| `likes` / `reports` | رقم | |
| `parentId` | نص (اختياري) | إن كان ردًا: رقم التعليق الأصلي |
| `replyTo` | نص (اختياري) | `handle` الشخص الذي يُرد عليه |

حذف تعليق يحذف الردود التي تحته. وفي التواصل، **التعليق على سؤال هو إجابة**.

```json

```
في التواصل تُضاف: `type` و`communityId` و`branchId` و`tags`. الملفات المرفوعة لا تُحفظ في المسودة.

## 8. المجتمعات والفروع

```json
{
  "id": "frontend",
  "color": "#F97316",
  "members": 2340,
  "name": { "ar": "فرونت إند", "en": "Frontend" },
  "description": { "ar": "…", "en": "…" },
  "branches": [
    { "id": "frameworks", "name": { "ar": "…", "en": "Frameworks" }, "tags": ["React", "Vue"] }
  ]
}
```

- المجتمع `general` (عام) يعرض منشورات كل المسارات.
- الفرع الذي أضافته الإدارة أو وافقت على طلبه فيه أيضًا `isNew: true`.

### عضوية المستخدم

```json
{ "onboarded": true, "communities": ["general", "frontend"], "branches": ["frontend/frameworks"] }
```

- `onboarded`: هل اختار اهتماماته في أول دخول (صفحة «ما الذي يهمك؟»).
- الفرع يُكتب بالصيغة `"<communityId>/<branchId>"`.

**القواعد:**
- الانضمام لمجتمع لا يضمّه لفروعه تلقائيًا.
- مغادرة المجتمع تعني مغادرة كل فروعه.
- الانضمام لفرع من مجتمع غير منضم له يضمّه للمجتمع أيضًا.

### طلب فتح فرع جديد

| الحقل | المعنى |
|---|---|
| `id`، `communityId` | |
| `branchId` | رقم الفرع المقترح |
| `name`، `description` | اسم الفرع ووصفه |
| `tags` | أدواته |
| `reason` | سبب فتحه |
| `applicant` | `{ id, handle }` |
| `status` | `pending` أو `approved` أو `rejected` |
| `rejectReason` | `notEnough` أو `exists` (الفرع موجود) |
| `createdAt`، `reviewedAt`، `isNotified` | |

## 9. الامتحانات

| الحقل | النوع | المعنى |
|---|---|---|
| `id` | نص | |
| `author` | شخص مختصر | الناشر (صاحب شارة `scholar`) |
| `communityId` / `branchId` | نص | مكان الامتحان |
| `title` / `description` | نص | |
| `duration` | رقم | المدة بالدقائق |
| `createdAt` / `editedAt` | وقت | |
| `questions` | قائمة | الأسئلة |

**السؤال:**

| الحقل | النوع | المعنى |
|---|---|---|
| `id` | نص | |
| `text` | نص | نص السؤال |
| `options` | قائمة نصوص | الخيارات |
| `answer` | رقم | ترتيب الخيار الصحيح (يبدأ من 0) |
| `image` | نص أو null | `mediaId` لصورة السؤال |
| `table` | كائن أو null | جدول: `{ "rows": [["…","…"]], "hasHeader": true }` |
| `code` | نص أو null | مقطع برمجي |
| `explanation` | نص أو null | شرح الإجابة (يظهر بعد التصحيح) |

**نتيجة الطالب:**
```json
{ "answers": [1, 0, null, 2, 1], "score": 3, "total": 5, "finishedAt": 1731590400000 }
```
`answers`: الخيار الذي اختاره لكل سؤال، و`null` لسؤال لم يُجب عنه.

> **مهم للخادم:** الإجابة الصحيحة (`answer`) و`explanation` **يجب ألّا تُرسل للطالب قبل أن يسلّم الامتحان**، والتصحيح يكون على الخادم. حاليًا تُحسب في المتصفح لأنه لا يوجد خادم.

تعديل الامتحان بعد نشره يحذف النتائج القديمة، لأن الأسئلة قد تكون تغيّرت.

## 10. الدورات

| الحقل | النوع | المعنى |
|---|---|---|
| `id` | نص | |
| `author` | شخص مختصر | الناشر (صاحب شارة `scholar`) |
| `communityId` / `branchId` | نص | |
| `title` / `description` | نص | |
| `level` | نص | `beginner` أو `intermediate` أو `advanced` |
| `status` | نص | `draft` (مسودة، يراها صاحبها فقط) أو `published` (منشورة) |
| `students` | رقم | عدد المسجّلين |
| `createdAt` / `updatedAt` / `publishedAt` / `editedAt` | وقت | |
| `lessons` | قائمة | الدروس |

**الدرس:**
```json
{ "id": "l-1", "title": "…", "duration": 12, "notes": "شرح مكتوب", "video": { "mediaId": "…", "name": "lesson.mp4" } }
```
`duration` بالدقائق، و`video` اختياري. **رقم الدرس يبقى ثابتًا عند تعديل الدورة**، حتى لا يضيع تقدّم الطلاب.

**تقدّم الطالب في دورة:**
```json
{ "done": ["l-1", "l-2"], "enrolledAt": 1731590400000 }
```
وجوده يعني أن الطالب مسجّل، وإلغاء التسجيل يحذفه.

## 12. جلسة الدراسة

**جدول المراحل (المؤقّت):**
```json
{
  "repeat": true,
  "segments": [
    { "id": "s1", "kind": "study", "minutes": 25, "sounds": ["rain"] },
    { "id": "s2", "kind": "break", "minutes": 5, "sounds": [] }
  ]
}
```
- `kind`: `study` (دراسة) أو `break` (استراحة).
- `sounds`: أرقام الأصوات التي تعمل في المرحلة.

**تفضيلات الجلسة:** `{ "sceneId": "espresso", "goal": "هدف الجلسة", "taskId": "رقم مهمة من خطتي أو null" }`

**إحصائيات الدراسة (لكل يوم):**
```json
{ "2026-11-14": { "minutes": 150, "rounds": 6 } }
```
المفتاح هو التاريخ بالتوقيت المحلي. منه تُحسب: دقائق اليوم، وآخر 7 أيام، والأيام المتتالية (`streak`)، ومجموع الدقائق.

## 14. المكتبة (الأصوات والخلفيات)

**صوت:** `{ "id", "name", "icon", "src" }`. أصوات المنصة الأساسية تُولَّد داخل المتصفح (`recipe`) فلا تحتاج ملفات.

**خلفية:** `{ "id", "name", "src", "mediaType": "image" أو "video" }`.

**مكتبتي وجلستي** (أرقام فقط):
```json
{
  "sounds": ["rain", "waves"],
  "scenes": ["espresso"],
  "session": { "sounds": ["rain"], "scenes": ["espresso"] }
}
```
`session` هو ما نقله الطالب من مكتبته إلى صفحة الجلسة.

**طلب رفع صوت أو خلفية (من طالب):**

| الحقل | المعنى |
|---|---|
| `id` | يبدأ بـ `u-` للأصوات، و`s-` للخلفيات |
| `name` | الاسم |
| `duration` | مدة الصوت بالثواني (للأصوات) |
| `mediaType` | `image` أو `video` (للخلفيات) |
| `fileName`، `size` | اسم الملف وحجمه بالبايت |
| `uploader` | الشخص |
| `status` | `pending` أو `approved` أو `rejected` |
| `reason` | سبب الرفض |
| `createdAt`، `reviewedAt`، `isNotified` | |

**مكتبة المنصة الرسمية (ترفعها الإدارة):** `{ "id": "o-…", "kind": "sound" أو "scene", "name": { "ar", "en" }, "duration", "size", "createdAt" }`.

أقصى حجم مسموح: 15 ميغابايت للصوت، و60 ميغابايت لفيديو الخلفية.

## 15. خطتي

```json
{
  "mode": "daily",
  "dayStart": "08:00",
  "tasks": [
    { "id": "…", "title": "مراجعة قواعد البيانات", "minutes": 45, "kind": "study", "status": "pending", "day": 0 }
  ]
}
```

| الحقل | المعنى |
|---|---|
| `mode` | طريقة العرض: `daily` (يومية) أو `weekly` (أسبوعية) |
| `dayStart` | وقت بداية اليوم الدراسي |
| `kind` | `study` (دراسة) أو `rest` (راحة) |
| `status` | `pending` (لم تُعلَّم) أو `done` (تمت) أو `missed` (فاتت) |
| `day` | يوم الأسبوع: **السبت = 0** ... الجمعة = 6 |

**الخطة اليومية والأسبوعية قائمة واحدة:** اليومية تعرض مهام اليوم فقط، والأسبوعية تعرض كل المهام موزّعة على الأيام.

## 16. البلاغات والحجب

**بلاغ:**

| الحقل | المعنى |
|---|---|
| `id` | |
| `targetType` | نوع المحتوى: `post` أو `exam` أو `course` أو `live` |
| `targetId`، `title` | المحتوى المُبلَّغ عنه وعنوانه |
| `reason` | `wrong` (معلومة خاطئة) أو `inappropriate` (غير لائق) أو `spam` أو `copyright` (حقوق نشر) أو `other` |
| `note` | ملاحظة اختيارية |
| `reporter` | `{ id, handle }` |
| `ownerId` | صاحب المحتوى |
| `status` | `pending` أو `removed` (حُذف المحتوى) أو `dismissed` (لا توجد مخالفة) |
| `createdAt` | |

كل مستخدم يبلّغ مرة واحدة فقط على نفس المحتوى. بلاغات المنشورات في «ادرس معي» عدّاد فقط (`reports`)، والمنشور يُخفى للمراجعة بعد عدد معيّن من البلاغات.

**الحجب:** المحتوى المحجوب يُكتب بالصيغة `"<targetType>:<targetId>"` (مثل `"post:cp-1"`). يختفي عن الجميع، إلا عن الإدارة وصاحبه، ويصل لصاحبه إشعار.

**طلب مراجعة (من صاحب محتوى محجوب):**
```json
{ "id": "appeal-…", "targetType": "post", "targetId": "…", "title": "…", "note": "…", "owner": { "id", "handle" }, "status": "pending", "createdAt": 1731590400000 }
```
`status`: `pending` أو `approved` (رُفع الحجب) أو `rejected`.

> **مهم للخادم:** الحجب وقرارات البلاغات والشارات والطلبات **للإدارة فقط**، والخادم هو الذي يتحقق أن من يقوم بها أدمن فعلًا.
